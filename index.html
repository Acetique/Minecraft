Galerie interactive avec portraits, statistiques, comportements, butins, lieux d'apparition et fiches de découverte. Les renseignements détaillés sont des fiches de référence pour Java, à vérifier selon la version du jeu.

Galerie de référence disponible immédiatement. Les portraits et les données synchronisées nécessitent Internet.

Sources : Minecraft Data pour les biomes et statistiques techniques ; liens Minecraft Wiki pour les mécaniques et changements par version.
